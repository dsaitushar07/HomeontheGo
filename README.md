# 🏡 HomeontheGo

**HomeontheGo** is a full-stack web application for property listings, inspired by platforms like Airbnb.  
It allows users to explore, create, and manage listings with authentication, image uploads, ratings, and maps.

## LIVE: https://homeonthego.onrender.com/listings

## 🚀 Features

- **Property Listings (CRUD)** – Users can create, view, update, and delete property listings.
- **Dynamic EJS Templates** – Server-side rendering with reusable, responsive views.
- **Authentication & Authorization** – Implemented using Passport.js for secure login, logout, and role-based access control.
- **Ratings & Reviews** – Only authenticated users can add, edit, or delete their own reviews.
- **Image Uploads** – Integrated image upload functionality for property listings.
- **Interactive Maps** – Integrated Mapbox API to display property locations on dynamic maps.
- **Validation & Error Handling** – Both client-side and server-side validations with robust error messages.
- **Responsive UI** – Styled with Bootstrap for seamless experience across devices.

---

## 🛠 Tech Stack

- **Frontend:** HTML, CSS, EJS, Bootstrap, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas (cloud database)
- **Authentication:** Passport.js
- **Maps:** Mapbox API
- **Deployment:** Render
